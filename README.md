# 💗 Site Para Meu Amor 🩰

### Um pedacinho do meu coração transformado em código.

Este projeto foi desenvolvido com muito carinho para uma pessoa extremamente especial na minha vida. ❤️

A ideia é transformar sentimentos, memórias e pequenos detalhes em uma experiência interativa, romântica e única.

Mais do que um simples site, este projeto é uma forma de demonstrar amor através da programação.

---

## 🌷 Sobre o projeto

**Site Para Meu Amor** é um site romântico e interativo, inspirado no universo do ballet e dedicado à minha bailarina favorita. 🩰

Cada página foi pensada para proporcionar uma surpresa diferente, reunindo mensagens de carinho, animações e momentos especiais.

## ✨ Funcionalidades

- 💌 **Cartinha surpresa:** uma carta romântica que pode ser aberta através de uma animação interativa.
- 🫙 **Potinho do amor:** um potinho virtual com 20 motivos pelos quais eu amo você, revelados em pequenos bilhetes.
- 🧩 **Quebra-cabeça especial:** um jogo interativo que revela uma fotografia ao ser completado.
- 🩰 **Tema inspirado no ballet:** elementos visuais delicados que representam uma das maiores paixões da pessoa homenageada.
- 📱 **Design responsivo:** interface adaptada para celulares, tablets e computadores.
- 💗 **Animações e interatividade:** pequenos detalhes que tornam a experiência ainda mais especial.

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5** — Estrutura das páginas.
- **CSS3** — Estilização, responsividade e animações.
- **JavaScript** — Interatividade, efeitos e funcionamento das surpresas.
- **Git e GitHub** — Versionamento e armazenamento do código.
- **Vercel** — Hospedagem e publicação do site.

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Lukzinhoo/site-para-meu-amor.git
```

2. Abra a pasta do projeto no Visual Studio Code.

3. Abra o arquivo `index.html` no navegador ou utilize uma extensão como **Live Server**.

Não é necessário instalar bibliotecas ou dependências externas para executar as páginas estáticas do projeto.
